Slide 02 | Requirement

Requirement: SAP Data, PTS และ VMCS

Structure มีการเปลี่ยนแปลง โดย SAP เตรียมข้อมูลตาม Standard และ PTS เลือกเฉพาะฟิลด์ที่จำเป็นต่อการใช้งาน

Data structure ที่ต้องรองรับ

  • ปรับจำนวนคอลัมน์ตามข้อมูล Standard จาก SAP
  • ปรับ Field Type, Length หรือ Property อื่น ๆ ที่เกี่ยวข้อง
  • ค่า Code ที่ Map บน PTS อาจเปลี่ยน เช่น Payment Block และ Payment Method จึงต้อง Initial Master ใหม่

Integration และการใช้งาน

  • PTS ส่ง Filter ไปยัง SAP เพื่อดึงเฉพาะข้อมูลที่ต้องใช้
  • ทำ Data Conversion ก่อนบันทึกข้อมูลลง Database ของ PTS
  • Vendor ใช้งาน Portal และ Landing Page ผ่าน VMCS เพื่อเข้าสู่ Application PTS
  • Share OutSystems Block หรือ Component อื่น ๆ เพื่อให้ VMCS เรียกใช้งานได้

VMCS เป็นจุดเริ่มต้น

  • Vendor เข้าใช้งานและลงทะเบียนผ่าน VMCS
  • VMCS ส่งข้อมูลมายัง Module PaymentTrackingInterface ผ่าน service PaymentTracking_CreateUpdateAccount

PTS ประมวลผลข้อมูลธุรกิจ

  • ดึง Invoice และ Vendor Master จาก SAP ผ่าน Timer ที่เรียก GC SAP Gateway
  • ทำ filter และ data conversion ก่อนบันทึก Database

Slide 04 | SAP data schedule

Timer สำหรับรับข้อมูลจาก SAP

PTS รัน Timer เพื่อเรียก API ของ application GC SAP Gateway และคัดเลือกข้อมูลก่อนนำมาใช้งาน

Timerเวลาเงื่อนไขSAPTimer_1_BusinessPartner_Daily05:00, 12:00CreationDate หรือ LastChangeDate เป็นวันปัจจุบันSAPTimer_2_InvoiceTransaction_Daily05:15, 12:15(AccountingDocumentType eq 'KA' or AccountingDocumentType eq 'KB' or AccountingDocumentType eq 'KE' or AccountingDocumentType eq 'KF' or AccountingDocumentType eq 'KW' or AccountingDocumentType eq 'KX' or AccountingDocumentType eq 'ZK') and IsReversed eq false and not startswith(Supplier,'26') and not startswith(Supplier,'98')

เงื่อนไข Invoice: รับเฉพาะ AccountingDocumentType = KA, KB, KE, KF, KW, KX หรือ ZK; ต้องไม่ถูก reverse และตัด Supplier ที่ขึ้นต้นด้วย 26 หรือ 98 ออก เพื่อคัดเฉพาะรายการที่ PTS ต้องใช้

Slide 05 | Database interface tables

ตารางข้อมูล Interface

ตารางชั่วคราวใช้รองรับข้อมูลที่รับเข้ามาก่อนตรวจสอบและซิงก์ไปยังตารางหลัก ส่วนตาราง log ใช้ติดตามการทำงานของ Interface

M_VENDOR_CONTACTข้อมูล VENDOR_CONTACT ทั้งหมดเก็บข้อมูลผู้ติดต่อของ Vendor เพื่อให้ระบบอ้างอิงรายละเอียดการติดต่อได้M_VENDOR_IMPORT_TEMPTemp M_VENDOR_IMPORT_TEMP แล้ว sync ไปยัง M_VENDORตารางพักข้อมูล Vendor ชั่วคราวก่อนตรวจสอบและซิงก์เข้าสู่ตาราง Vendor หลักT_INVOICE_PAYMENTข้อมูล INVOICE ทั้งหมดตารางหลักสำหรับเก็บข้อมูล Invoice/Payment ที่พร้อมใช้งานใน PTST_INVOICE_INTERFACE_TEMPTemp T_INVOICE_INTERFACE_TEMP แล้ว sync ไปยัง T_INVOICE_PAYMENTตารางพักข้อมูล Invoice จาก Interface ก่อนซิงก์เข้าสู่ตาราง Invoice หลักL_INTERFACE_LOGLog INTERFACE ทั้งหมดจาก SAP, VMCSใช้ตรวจสอบผลการรับ-ส่งข้อมูล เวลาเกิดเหตุ และข้อผิดพลาดของ Interface
