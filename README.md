# KT-Payment

Repository นี้เก็บเอกสาร, สไลด์, และรูปภาพประกอบของงาน KT-Payment: VMCS และ Payment Tracking PTS

## Web Page

เปิดหน้าเว็บได้จากไฟล์ `index.html`

ถ้าต้องการเปิดผ่าน GitHub Pages จาก URL สาธารณะ repository ต้องเป็น public หรือบัญชี GitHub ต้องอยู่ใน plan ที่รองรับ Pages สำหรับ private repository

## Files

- `index.html` - หน้าเว็บสำหรับดูเอกสารและรูปภาพประกอบ
- `KT_Support_VMCS_PaymentTracking_PTS.docx` - เอกสารรายละเอียดงาน
- `KT_Support_VMCS_PaymentTracking_PTS.pptx` - สไลด์นำเสนอ
- `*.jpg` - รูปภาพประกอบ

```bash
git remote add origin <repository-url>
git branch -M main
git add .
git commit -m "Initial KT support materials"
git push -u origin main
```
